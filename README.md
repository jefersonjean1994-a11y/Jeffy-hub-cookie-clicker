# 🖤 Jeffy Hub

A dark/emo-style hub for Cookie Clicker with automation, customization, and a customizable GUI.

## ✨ Features

- 🍪 OP Auto Clicker
- 💰 0-Cost Buildings
- 🛒 Auto Buy
- ♾️ Infinite Heavenly Chips
- ⭐ Cursor Level 10,000
- 🏪 Jeffy's Bakery
- 🎨 Dark animated GUI
- ⌨️ Customizable keybinds
- 🎵 Calm music support
- 🔇 Sound control
- 👻 Hide/Show GUI
- 🗑️ Destroy Hub
- 🔐 Key System

## ⌨️ Default Keys

| Key | Feature |
|---|---|
| `P` | Hide/Show Hub |
| `C` | Auto Click |
| `F` | 0-Cost Buildings |
| `B` | Auto Buy |
| `H` | Infinite Heavenly Chips |

Keys can be changed from the **Settings** tab.
